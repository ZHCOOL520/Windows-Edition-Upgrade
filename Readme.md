## 一、这个工具是做什么的

- 想装专业版，安装程序却因为固件里内置的密钥自动跳到家庭版？
- 想从专业版升级到专业工作站版，手上却没有 GLVK 密钥？
- 装好了专业版才发现自己只有家庭版授权，又懒得全新安装？
- 想从家庭版直接升级到企业版，技术上和升级到专业版没区别，但微软的授权策略不给你这条路？
- 而且零售版 ISO 或 MediaCreationTool 做出来的 U 盘里根本没有企业版？
- 想从专业教育版退回专业版，却发现没有对应的升级/降级路径？
- 全新安装可以用改过的 `EI.cfg` 解决，但就地升级根本不给你选版本的机会？
- 想在不折腾 WIM 的前提下，做一个「几乎全版本」的安装介质？

这个工具就是为此准备的。现在有批处理版和图形界面版两个版本，功能一致。

## 二、重要警告（使用前务必阅读）

1. **本工具不是激活工具**
   它只使用微软官方的预安装密钥（OEM/GLVK），这些密钥仅用于安装时选择版本，不能用来激活系统。激活仍然需要你自己的正版授权。

2. **方法 4（强制升级）会修改注册表**
   它会临时把 `ProductName` / `EditionID` / `CompositionEditionID` 改成目标版本的值，让安装程序「以为」你已经是那个版本。
   这是微软完全不支持的做法，风险自负。建议操作前先备份系统和重要数据，并确保有可用的恢复介质。如果写错了版本，用正确版本再执行一次强制升级即可覆盖回来。

3. **工具可以放在任意位置**
   脚本会先检查自己所在目录和当前目录，找不到安装介质时会让你选择：自动扫描所有盘符、手动输入/拖入文件夹，或直接选择 ISO 并自动挂载。安装介质必须同时包含 `setup.exe` 和 `sources` 文件夹。

4. **LTSC 和 Server 版本不在普通安装介质里**
   Windows 10 企业版 LTSC 2021、Windows 11 企业版 / IoT 企业版 LTSC 2024、Server 2022、Server 2025 都必须自己准备对应的 ISO。普通消费者版 ISO 里没有这些镜像，安装程序也无法凭空「变」出来。

5. **升级过程请勿断电**
   就地升级会经历重启和较长时间的配置阶段，期间不要强制关机。

6. **授权合规**
   请只在你有合法授权的场景下使用版本切换功能。

7. **Windows 10 和 Windows 11 SE 已结束支持**
   Windows 10 已于 2025 年 10 月 14 日停止支持，消费级 ESU 计划延续到 2027 年 10 月 12 日；Windows 11 SE 已于 2026 年 10 月结束支持。条件允许时，建议升级到 Windows 11 26H2。

## 三、使用方法（批处理版 · 已冻结）

> 批处理版文件名为 `无损跨版本升级Windows-BAT版.bat`，功能保持现状，不再更新；后续新功能只加在 EXE 版里。

### 第一步：选择安装介质

运行后先自动扫描一遍：所有盘符（C-Z）和脚本所在目录。扫到就直接列出来，输入编号选中即可。

```
  扫描到 2 个可用的安装介质:

     1. F:\
     2. D:\ISO\Win11_26H2\
```

一个都没扫到，或者想用别的目录，就从下面选：

| 选项 | 说明 |
| --- | --- |
| `F` | 弹出文件夹选择窗口 —— 命令行窗口没法直接拖文件，用这个最省事 |
| `I` | 弹出 ISO 选择窗口，选中后自动挂载 |
| `M` | 手动粘贴路径，支持带引号和空格的路径 |
| `R` | 重新扫描（例如刚挂载完 ISO） |
| `0` | 退出 |

在输入框里也可以直接粘贴路径，或把文件夹 / ISO 拖到窗口里再回车；以 `.iso` 结尾会自动走挂载流程。安装介质必须同时包含 `setup.exe` 和 `sources` 文件夹。

挂载使用系统自带的 `Mount-DiskImage`，不需要第三方工具。

### 第二步：选择目标版本

输入 `1-27` 选择预置版本。列表里没有的版本用 `28`：

**28. 自定义版本** —— 自己提供 25 位预安装密钥（GLVK / OEM），带不带连字符都可以。之后还可以选择性填写：

- `EditionID`：强制升级（方法 4）需要，例如 `Core`、`Professional`、`EnterpriseS`；
- `ProductName`：直接回车就使用当前系统的 ProductName。

只做方法 1 或方法 3 的话，这两项可以留空。

选定后会进入执行方式页面，按 `0` 可以返回重选。

### 第三步：选择执行方式

| 按键 | 方法 | 说明 |
| --- | --- | --- |
| `k` | 方法 1 | 用 `slmgr` 直接安装所选密钥，只切换版本，不做就地升级 |
| `s` | 方法 2 | 不指定版本直接升级，由安装程序自行判断，等同普通就地升级 |
| `u` | 方法 3 | 升级到所选版本，安装程序会自动套用对应的预安装密钥 |
| `f` | 方法 4 | 强制升级到所选版本，会修改注册表来「伪装」版本，可跨过官方升级路径限制（包括降级） |
| `0` | 返回 | 回到版本列表重新选择 |

方法 4 需要输入 `Y` 二次确认。执行后升级由安装程序接管，本窗口会在启动安装程序后关闭。

> **提示**：即使 ISO 里没有目标版本，只要包含家庭版 / 家庭版 N / 专业版 / 专业版 N 中的一种，安装程序通常可以在线按需生成其他版本。例如 ISO 里只有专业版，用企业版密钥启动安装，也能得到企业版。

### 源码环境与构建

- 工程目标：`.NET 10`、Windows App SDK `2.6.5`，固定为 unpackaged `x64`；目标平台 API 为 Windows 11 SDK 22621，最低声明 Windows 10 2004（19041）。最低声明不代表已完成所有系统及 Server 版本的运行验证。
- 开发环境需要 .NET 10 SDK、Windows SDK 和支持 WinUI / Windows App SDK 的构建工具；首次构建需要访问 NuGet。
- 工程使用 `.NET` + Windows App SDK 自包含单文件发布：所有依赖打进一个 EXE，分发时只需这一个文件，不需要另外安装 .NET 或 Windows App SDK 运行时。
- 旧 WinForms 源码保留作迁移参考，显式排除在新项目编译列表之外；新入口仅为 `App.xaml` / `App.xaml.cs`。

可使用以下命令重新还原、构建和发布（本次已完成还原及 Release 发布）：

```powershell
dotnet restore .\src\UpgradeTool.csproj
dotnet build .\src\UpgradeTool.csproj -c Release --no-restore
dotnet publish .\src\UpgradeTool.csproj -c Release --no-restore -o .\publish\win-x64
```

发布结果为单个 EXE，无需附带其他文件。实际交付前仍需验证主题、DPI、窄窗口、管理员选择器、快捷键、取消流程及日志导出；本次未执行密钥安装、系统版本注册表改写或系统升级。

编译产物（`src/bin`、`src/obj`、`publish`）已加入 `.gitignore`，仓库只保留源码；EXE 通过 GitHub Releases 作为附件分发。

## 七、测试情况与说明

- 曾用只含家庭版的 WIM 测试：用专业版密钥启动安装，结果仍然进入家庭版安装流程（符合预期）。
- 随后在 WIM 中只添加专业版镜像，再用专业版密钥启动，就正确进入专业版安装流程。
- 中断安装后改用专业工作站版密钥启动，安装程序从专业版自动生成了专业工作站版。
- 用消费者版 ISO（原本不含企业版）配合企业版密钥，也成功自动生成并安装了企业版。
- 以上测试均在线完成（需要联网）。

**2026 年版本现状（2026 年 11 月核对）**

- Windows 11 当前主线版本是 26H2（2026 年 9 月 29 日发布）；26H1 只随 2026 年新设备提供，不用于现有设备的就地升级。
- Windows 11 23H2 已全面结束支持；24H2 家庭版 / 专业版已结束更新，企业版支持到 2027 年 10 月 12 日；25H2 家庭版 / 专业版支持到 2027 年 10 月 12 日，企业版支持到 2028 年 10 月 10 日。

**LTSC 说明**

LTSC 版本不在普通安装介质中，需要用对应的 LTSC ISO。Windows 10 企业版 LTSC 2021（含 IoT/N）已用官方 LTSC 2021 ISO 测试通过。
